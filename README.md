# Prawin A — Next.js Portfolio

A modern, animated developer portfolio built with Next.js App Router, React, Framer Motion and Lucide icons.

## Run locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

## Replace profile photo

The current `public/profile.png` is the professional portrait generated for this portfolio. Replace it with another image using the same filename if you want to change the portrait.

## Deploy

This project can be deployed directly to Vercel or any Next.js-compatible host.
